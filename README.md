# 🌸 ARomanova Perfume Shop - Frontend

A modern perfume e-commerce frontend built with Next.js, React, TypeScript, and Tailwind CSS.

## ✨ Features

- 🔐 User Registration & Login
- 👤 User Authentication
- 🌸 Perfume Product Browsing
- 🔍 Product Search
- 🏷️ Product Categories
- 🛒 Shopping Cart
- 📦 Order Management
- 💳 Payment Pages
- 🔔 Notifications
- 👨‍💼 Admin Dashboard
- 📦 Inventory Management
- 📊 Analytics

## 🛠️ Technologies

- Next.js
- React
- TypeScript
- Tailwind CSS
- JavaScript
- CSS

## 🔗 Backend Connection

Frontend:

http://localhost:3000

Backend:

http://localhost:4000

Example API:

http://localhost:4000/api/products

Architecture:

Next.js Frontend
        ↓
HTTP Request
        ↓
Node.js + Express Backend
        ↓
MongoDB

Backend Repository:

https://github.com/elzabel2321-ops/perfume-backend

## 🔐 Environment Variables

Create:

.env.local

Do not commit passwords, API keys, JWT secrets, or database credentials.

Example:

.env.example

## 🚀 Installation

Clone the repository:

git clone https://github.com/elzabel2321-ops/perfume-frontend.git

Enter the project:

cd perfume-frontend

Install dependencies:

npm install

## ▶️ Development

npm run dev

Open:

http://localhost:3000

## 🧹 Lint

npm run lint

## 🏗️ Build

npm run build

## ▶️ Production

npm start
